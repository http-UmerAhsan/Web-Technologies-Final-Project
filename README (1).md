**Laravel 10**, **MySQL**, **Yajra DataTables**, and **Laravel Mail**
--- designed for the Pakistani market with PKR currency.

## 🚀 Setup

### 1️⃣ Clone Repository

``` bash
git clone https://github.com/your-repo/nike-pakistan.git
cd nike-pakistan
```

### 2️⃣ Install Dependencies

``` bash
composer install
npm install
npm run dev
```

### 3️⃣ Configure Environment

``` bash
cp .env.example .env
php artisan key:generate
```

Update `.env`:

``` env
DB_DATABASE=your_db
DB_USERNAME=root
DB_PASSWORD=
```

------------------------------------------------------------------------

### 4️⃣ Run Migrations

``` bash
php artisan migrate --seed
```

------------------------------------------------------------------------

### 5️⃣ Start Server

``` bash
php artisan serve
```

Visit: http://localhost:8000
